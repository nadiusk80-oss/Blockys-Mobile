## Changes made by this fork (2026-11-20)

- Rebranding applied at build time by `blockys/brand.py`:
  - Visible name: `Blockys Mobile` (instead of `Amethyst`).
  - Launcher and default profile icons regenerated from the Blockys artwork.
  - `minebutton_color` accent changed to `#3F6B32` and adaptive icon background to
    `#F4EFE2`.
  - "About" screen (`about_en.txt`) with the corresponding attribution.
- Own package identifier: `com.blockys.movil` (no `.debug` suffix), so it does not conflict
  with PojavLauncher or Amethyst.
- Own build workflow (`.github/workflows/android.yml`) that downloads the public Java 8
  binpack, applies branding, builds and publishes the APK.
- README and this NOTICE rewritten.

## Changes made by this fork (2026-11-21)

- Local (offline) accounts no longer require a Microsoft account. `brand.py` rewrites
  `SelectAuthFragment` so the "Local account" button opens the local login screen directly
  instead of checking for an online profile, and `ProfileTypeSelectFragment` so Fabric,
  Forge, NeoForge, Quilt, OptiFine, modpack, LWJGL3ify and BTA profile creation is available
  without one.
- `LocalLoginFragment` no longer bounces back to the main menu when there is no online
  profile. Account creation uses PojavLauncher's original flow unchanged: the fragment sends
  the new username through `ExtraCore` (`MOJANG_LOGIN_TODO`), the account spinner in
  `LauncherActivity` saves it and adds it to its list, and the new account becomes the
  selected profile immediately.
- `MainMenuFragment` no longer gates the jar installer or the "open directory" button behind
  an online profile; `ModpackCreateFragment` no longer gates modpack creation either.
- `MinecraftDownloader.start` no longer refuses to download the game for local profiles.
  Amethyst only verified that the version was already installed unless the current account
  was a non-local, connected profile; upstream PojavLauncher calls `downloadGame`
  unconditionally. The offline (no network) check and its message are kept.
- The demo profile restrictions are unchanged.

The execution engine, runtime selection and native modules are unchanged.

## Changes made by this fork (2026-11-26)

- Minecraft 26.x on Android. `app_pojavlauncher/src/main/jni/native_hooks/sdl_hook.c` is a
  native module built into the launcher: it installs bytehook inline hooks on `SDL_LoadObject`
  (when the plain dlopen of the bundled `libEGL_mesa.so` fails, it retries through
  `loader_dlopen`), on `SDL_CreateWindow` (a second window request returns the first, shared,
  window instead of failing with "Android only supports one window") and on `SDL_DestroyWindow`
  (the shared window stays alive until the last alias is destroyed). `brand.py` makes
  `MinecraftGLSurface` write `fullscreen:false` into `options.txt`, and gives profiles that
  need Java 25 the `opengles3_desktopgl_zink_kopper` renderer when they have none.
- `RendererFallback` (generated by `brand.py` as `utils/RendererFallback.java`) runs when the
  game exits with a non-zero code: if the profile uses Zink and the tail of `latestlog.txt`
  contains "Could not initialize EGL", it writes `opengles_mobileglues` into the current
  profile so the next start uses MobileGlues. `brand.py` also patches the exit handler in
  `JREUtils` to call it and to show the new `mcn_exit_renderer_switch` string (English and
  Spanish).
